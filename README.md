#  Expense Tracker

A full-stack Expense Tracker application built using **React, MongoDB, JSON, and JavaScript**. This application allows users to manage their finances by adding and tracking income and expenses, viewing their current balance, and maintaining a history of transactions.

##  Features

*  Add income and expense transactions
*  Delete transactions
*  View current balance
*  Track total income
*  Track total expenses
*  View transaction history
*  Real-time UI updates with React
*  Store transaction data in MongoDB
*  Responsive and user-friendly interface

##  Built With

### Frontend

* React
* JavaScript (ES6+)
* CSS
* JSON

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
